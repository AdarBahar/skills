# skills

> Orientation doc (setup, deploy, connection to dotfiles and bearings): `$BEARINGS_VAULT_DIR/working-configuration/skills/skills.md`. Get the value of `BEARINGS_VAULT_DIR` from `~/.bearings/bearings.env`.

## Rules

- In a skill, select a model only by its alias: `haiku`, `sonnet`, `opus`, or `fable`. Do not write a version number, such as "Sonnet 5.5". Claude Code maps each alias to the newest model of that tier, so the skill stays correct after a new release.
- Describe a tier by its purpose (for example "the fastest and cheapest tier"), not by its version.
